# Pak Wood Sawdust Exports Website

A responsive static HTML/CSS/JavaScript website for marketing wood sawdust and wood shavings from Pakistan to GCC buyers.

## Before publishing
Open `script.js` and replace:
- `CONTACT_EMAIL`
- `WHATSAPP_NUMBER`
- `DISPLAY_PHONE`

The quote form uses the visitor's email client (`mailto:`), so no server/database is required.

## Files
- `index.html` — website
- `style.css` — design
- `script.js` — menu, WhatsApp and quote form
- `assets/hero-reference.png` — generated visual reference

## Free hosting
GitHub Pages can host static HTML/CSS/JS directly from a repository. Create a repository, upload these files, then enable Pages under Settings → Pages and choose a publishing branch.
